# Google Play 등록 문안 (ko-KR)

Play Console 글자 수 제한에 맞춰 작성함. 앱 이름 30자, 간단한 설명 80자, 자세한 설명 4000자, 출시 노트 500자.

## 앱 이름 (30자)

```
일본 메뉴 번역기
```

## 간단한 설명 (80자)

```
일본 메뉴판을 찍으면 한국어 뜻과 한글 발음을 바로 알려주는 오프라인 번역기
```

## 자세한 설명 (4000자)

```
일본 여행 중 메뉴판 앞에서 막막했던 적 있나요?
메뉴판을 사진으로 찍기만 하면 한국어 뜻과 한글 발음을 바로 보여드려요.

■ 주요 기능

📷 메뉴판 스캔
카메라로 찍거나 갤러리 사진을 고르면 일본어 메뉴를 자동으로 인식해 한국어로 번역해요. 가로쓰기는 물론 세로쓰기 메뉴판도 인식해요. 메뉴 이름 옆에 가격도 함께 보여줘요.

🔤 한글 발음 표기
"唐揚げ → 가라아게"처럼 일본어 읽는 법을 한글로 알려줘서, 점원에게 그대로 읽어 주문할 수 있어요.

🍣 일본 음식 사전 내장
이자카야·라멘집·초밥집에서 자주 나오는 메뉴를 직접 정리한 사전으로 먼저 번역해요. 일반 번역기가 어색하게 옮기는 "もつ鍋(곱창전골)", "ぼんじり(닭 꼬리살)" 같은 용어도 자연스럽게 나와요.

🗣 역번역 (한국어 → 일본어)
"이거 얼마예요?"처럼 한국어를 입력하면 일본어와 한글 발음을 보여주고, 음성으로 읽어줘요. 일본어를 말하면 한국어 뜻을 알려주는 음성 입력도 지원해요.

💴 가격 원화 환산
메뉴 가격이 오늘 환율로 원화로 함께 표시돼요. 인터넷이 없으면 마지막으로 받은 환율을 써요. (유럽중앙은행 기준 환율이라 실제 환전·카드 환율과는 달라요.)

🕘 스캔 기록
이전에 번역한 메뉴를 다시 볼 수 있어요.

✂ 영역 선택
사진 속에서 번역하고 싶은 부분만 골라서 다시 인식할 수 있어요.

■ 이런 분께 추천해요
- 일본어를 몰라도 현지 식당에서 자유롭게 주문하고 싶은 분
- 로밍·데이터 없이도 번역기를 쓰고 싶은 분

■ 오프라인 지원
처음 한 번 번역 언어팩(일본어↔한국어)을 내려받으면 이후에는 인터넷 없이도 인식과 번역이 가능해요. 데이터가 불안정한 지하 식당가나 해외에서도 안심하고 쓸 수 있어요.

■ 권한 안내
- 카메라: 메뉴판을 촬영해 글자를 인식하기 위해 사용해요.
- 마이크: 역번역의 음성 입력 기능에서만 사용해요.

오프라인 모드에서는 찍은 사진이 기기 안에서만 처리되며 서버로 전송되지 않아요.
```

### 데이터 보안(Data safety) 양식 답변 가이드

앱 코드 기준(src/lib/translate.ts, wikipedia.ts)으로 정리함. **제출 전에 실제 동작과 한 번 더 대조할 것.**

- **오프라인 모드**: 사진·음성이 기기 밖으로 나가지 않음.
- **온라인 번역 모드**를 켠 경우 인식된 **일본어 텍스트**가 `translate.googleapis.com`으로 전송됨 → "앱 활동/기타 사용자 콘텐츠"를 *공유*(번역 처리 목적, 선택 기능)로 선언하는 것이 안전함.
- **음식 설명 보기**를 누르면 메뉴 이름이 `ko.wikipedia.org`로 전송됨 → 위와 같이 선언.
- **환율 조회**: 메뉴 가격의 원화 환산을 위해 `api.frankfurter.dev`에 엔-원 환율을 요청함. 요청 본문에 사용자 데이터는 없으며 IP 주소만 통신 과정에서 전달됨 → 별도 수집 항목 없음(통신 상 IP는 "수집하지 않음"으로 답해도 되나, 불안하면 "기기 또는 기타 ID"가 아닌 점을 방침에 명시).
- **음성 입력**은 Android 기본 음성 인식(`SpeechRecognizer`)을 사용하며 기기/Google 서비스 설정에 따라 서버 처리될 수 있음 → 개인정보처리방침에 이 점을 명시할 것.
- **전송 중 암호화**: 예 (HTTPS).
- **삭제 요청 수단**: 서버에 저장하는 데이터 없음 (스캔 기록은 기기 내 저장, 앱 삭제 시 제거).

## 주의

- 온라인 번역은 Google 공식 API가 아닌 비공식 엔드포인트(`translate.googleapis.com/translate_a/single`)를 쓰고 있음. 이용 약관·차단 위험이 있어 사용자가 늘면 공식 Cloud Translation API(키는 서버에서 관리)나 오프라인 전용으로 전환할 것.
- 업로드 키(`~/.keystores/jpan-upload.jks`)와 `jpan-upload.properties`는 **반드시 따로 백업**. Play App Signing을 켜면 분실 시 Google에 재설정을 요청할 수 있지만 번거로움.
- 빌드는 `./scripts/build-aab.sh` 한 번으로 `dist/japan-menu-translator.aab`가 만들어짐. 업데이트 때는 `app.json`의 `android.versionCode`를 올려야 Play가 받아줌.
