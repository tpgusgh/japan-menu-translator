# Scan 결과 화면 단순화 — 설계

**날짜:** 2026-08-13
**배경:** 촬영 후 결과 화면이 원본사진(PhotoOverlay) + 번역캔버스(TranslatedLayout) + 카드목록(MenuList) 3중으로 쌓여 표시됨. 같은 정보가 세 번 반복되고 "다시 찍기" 버튼이 스크롤 맨 아래 있어 사용성이 나쁘다는 지적. 또한 캔버스는 실사용 테스트에서 겹침/작은 글씨 등 품질 문제로 이미 부정적 평가를 받은 상태.

## 결정

1. **결과 화면은 목록(MenuList) 단일 뷰로 통일한다.** 원본사진, 번역캔버스 모두 기본 노출에서 제외. 뷰가 하나뿐이므로 세그먼트 탭도 두지 않는다.
2. **상단 고정 헤더바**에 "다시 찍기" 버튼을 항상 노출한다(스크롤 없이 즉시 접근 가능). 처리중/에러 상태 텍스트도 헤더바 바로 아래 한 줄로 표시한다.
3. **촬영 전 화면의 온라인/오프라인 모드 토글**은 현재 카메라 위에 큰 버튼 2개로 떠 있는 것을 우측상단 작은 아이콘 버튼 + 탭 시 팝업(오프라인/온라인 선택, 설명 텍스트는 팝업 안에서만)으로 축소한다. 기본값은 오프라인 유지.
4. **TranslatedLayout.tsx는 삭제하지 않고 남긴다.** ScanScreen에서 import만 제거. 캔버스 품질을 나중에 개선하면 재사용할 여지를 남겨둠.
5. **PhotoOverlay.tsx는 삭제한다.** ScanScreen 외 다른 곳에서 쓰이지 않으므로 결과 화면에서 빠지면 완전히 미사용 상태가 됨.

## 컴포넌트 영향

- `ScanScreen.tsx`: 결과 분기 레이아웃을 헤더바(다시 찍기 버튼 + 상태 텍스트) + `MenuList`로 재구성. 촬영 전 화면의 모드 토글을 아이콘+팝업 방식으로 교체. 새 컴포넌트 파일은 만들지 않고 인라인으로 구현(둘 다 규모가 작아 분리 불필요).
- `PhotoOverlay.tsx`: 삭제.
- `TranslatedLayout.tsx`, `MenuList.tsx`, `src/lib/*`: 변경 없음.

## 테스트

순수 UI 레이아웃 재구성이며 번역/OCR 로직은 건드리지 않음. 새 테스트는 불필요, 기존 jest 스위트(`npx jest`)가 그대로 통과하는지만 확인한다.
