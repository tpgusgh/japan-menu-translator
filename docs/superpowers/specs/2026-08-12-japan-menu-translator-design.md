# 일본 여행 메뉴/간판 번역 앱 — 설계

## 목적
일본 여행 중 메뉴판/간판을 사진 찍으면 한국어로 번역해 보여주는 안드로이드 앱. 오프라인에서도 기본 번역과 발음이 동작해야 하고, 온라인이면 음식 설명을 추가로 보여준다. 로그인 없음. 기능 우선, 알아보기 쉬운 디자인.

## 범위
- 대상 플랫폼: 안드로이드 전용 (iOS 미지원)
- 언어쌍: 일본어 ↔ 한국어만
- 로그인/서버/DB 없음. 클라우드 종속 없이 오프라인 우선 동작.

## 기술 스택
- **Expo (Dev Client, prebuild)** + React Native. ML Kit 등 네이티브 모듈이 필요해 Expo Go로는 실행 불가, `expo run:android`로 커스텀 개발 빌드 사용.
- **카메라**: `expo-camera` — 사진 1장 촬영 (실시간 AR 오버레이 아님).
- **OCR**: `@react-native-ml-kit/text-recognition` — 구글 ML Kit 온디바이스 텍스트 인식. 완전 오프라인, 별도 다운로드 불필요, 일본어 문자 지원.
- **번역**: `@react-native-ml-kit/translate-text` — 구글 ML Kit 온디바이스 번역. ja↔ko 언어팩을 최초 1회 다운로드하면 이후 완전 오프라인 동작. (사용자가 요청한 "번역 파일 다운로드 후 오프라인 적용" 요구사항을 그대로 충족)
- **발음 추출**: `kuromoji.js` — 순수 JS 일본어 형태소 분석기, IPADIC 사전을 앱 에셋으로 내장(런타임 다운로드 없음, 항상 오프라인). 한자 포함 원문의 읽기(가나)를 추출.
- **가나→한글 발음 변환**: 자체 구현 매핑 테이블(의존성 없음). 국립국어원 일본어 표기법을 근사한 결정론적 함수.
- **음식 설명(온라인 전용)**: `ko.wikipedia.org` REST 요약 API, 무료·키 불필요. 항목별로 사용자가 탭했을 때만 지연 호출(불필요한 대량 요청 방지).
- **네비게이션**: React Navigation, 화면 2개 + 최초 실행 다운로드 화면.
- **로컬 저장**: 없음. 세션 내 상태만 유지(히스토리/영구 저장 기능 없음 — 요청 범위 밖, YAGNI).

## 화면 구성

### 1. 스캔 화면 (메인)
- 카메라 미리보기 → 촬영 버튼 → 사진 고정
- 고정된 사진 위, OCR로 찾은 각 텍스트 블록의 좌표에 한국어 번역을 오버레이로 표시. 원문은 작은 취소선 텍스트로, 그 옆/아래에 한글 발음 표시.
- 사진 아래로 스크롤하면 같은 항목들을 카드 리스트로 정리해서 보여줌 (원문 취소선 + 한글 발음 + 한국어 번역, 온라인이면 "설명 보기" 버튼).
- 다시 촬영 버튼으로 재시도 가능.

### 2. 역방향 번역 화면
- 한국어 텍스트 입력창
- 입력 즉시(또는 버튼) 일본어 번역 + 한글 발음 표시

### 3. 최초 실행 / 언어팩 다운로드 화면
- ML Kit ja↔ko 언어팩 다운로드 진행률 표시
- 완료되면 "오프라인 사용 가능" 배지 표시, 스캔/역번역 화면 진입 가능
- 언어팩 없으면 스캔·역번역 기능 진입 시 다운로드 화면으로 유도

## 데이터 흐름

### 스캔
1. 사진 촬영 → URI + 이미지 크기 획득
2. ML Kit Text Recognition으로 텍스트 블록 배열(텍스트 + 바운딩박스) 추출 (오프라인)
3. 각 블록 텍스트를 kuromoji로 토큰화 → 가나 읽기 추출 → 가나→한글 발음 변환 (오프라인)
4. 각 블록 텍스트를 ML Kit Translate(ja→ko)로 번역 (언어팩 다운로드 후 오프라인)
5. 필터링: 숫자/통화기호로만 이루어진 라인은 제외(가격 라인 노이즈 최소화). 별도 음식명 분류 AI는 사용하지 않음(YAGNI) — 나머지는 그대로 항목화.
6. 렌더링: 이미지 위 오버레이(바운딩박스를 화면 표시 크기로 스케일링) + 하단 카드 리스트
7. 네트워크 연결 확인 후, 사용자가 카드의 "설명 보기"를 탭하면 그 항목의 한국어 번역어로 위키백과 요약 조회, 결과 없으면 "설명 없음" 표시

### 역방향 번역
1. 한국어 입력
2. ML Kit Translate(ko→ja) → 일본어 텍스트
3. kuromoji로 결과 토큰화 → 가나 읽기 → 한글 발음 변환
4. 일본어 번역 + 한글 발음 표시

## 에러 처리
- 카메라 권한 거부 → 권한 요청 화면, 재시도 버튼
- 언어팩 미다운로드 상태에서 기능 접근 → 다운로드 화면으로 유도, 진행률 표시
- 최초 다운로드 시 인터넷 없음 → "최초 1회는 인터넷 연결이 필요합니다" 안내, 재시도 버튼
- OCR 결과 텍스트 없음 → "텍스트를 찾지 못했습니다. 다시 촬영해주세요" 안내, 크래시 없이 재촬영 유도
- 위키백과 조회 실패/오프라인 → 해당 카드에만 "오프라인 상태로 설명을 불러올 수 없습니다" 표시, 나머지 기능 정상 동작

## 테스트
- UI/카메라/OCR/번역 플로우는 안드로이드 에뮬레이터 또는 실기기에서 수동 확인(골든 패스: 사진→오버레이→리스트, 역번역 입력→출력).
- 가나→한글 발음 변환 함수는 순수 함수이므로 Jest 유닛 테스트 1개 작성(대표 가나 조합 케이스로 회귀 방지).
- 그 외 자동화 테스트 프레임워크는 도입하지 않음(범위 밖, YAGNI).

## 알려진 한계
- kuromoji 형태소 분석은 완벽하지 않아 드문 한자/신조어의 읽기가 부정확할 수 있음. ponytail: 명백히 틀린 케이스 발견 시 예외 사전으로 보정, 필요해지면 추가.
- 위키백과 요약은 메뉴 항목명과 정확히 매칭되지 않을 수 있어 흔한 음식이 아니면 설명이 안 나올 수 있음.
