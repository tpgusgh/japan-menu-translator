# 일본 메뉴 번역기 개인정보처리방침

시행일: 2026년 10월 9일

'일본 메뉴 번역기'(이하 "앱")는 이용자의 개인정보를 소중히 여기며, 아래와 같이 어떤 정보를 어떻게 다루는지 안내합니다.

## 1. 수집하는 정보

앱은 **회원가입이 없고, 개발자 서버로 개인정보를 수집·저장하지 않습니다.** 앱 기능을 위해 기기 안에서 다음 정보를 처리합니다.

| 항목 | 용도 | 저장 위치 |
|---|---|---|
| 카메라로 촬영하거나 갤러리에서 고른 사진 | 메뉴판의 일본어 글자 인식(OCR) | 기기 내부 (개발자 서버로 전송하지 않음) |
| 인식된 메뉴 텍스트와 번역 결과 | 화면 표시, '스캔 기록' 기능 | 기기 내부 (앱 삭제 시 함께 삭제) |
| 마이크 음성 | 역번역의 음성 입력 | 앱이 저장하지 않음 (아래 3항 참고) |

## 2. 기기 권한

- **카메라**: 메뉴판을 촬영해 글자를 인식하기 위해 사용합니다.
- **마이크**: '역번역'의 음성 입력 기능을 사용할 때만 사용합니다.

권한은 기기 설정에서 언제든 해제할 수 있으며, 해제해도 해당 기능 외 다른 기능은 계속 사용할 수 있습니다.

## 3. 외부 서비스로 전송되는 정보

기본 설정인 **오프라인 모드**에서는 사진과 글자가 기기 밖으로 전송되지 않습니다. 다음 경우에만 정보가 외부로 전송됩니다.

1. **온라인 번역 모드를 켠 경우**: 인식된 일본어 **텍스트**(사진 자체는 제외)가 번역을 위해 Google 번역 서버로 전송됩니다. 처리 방식은 [Google 개인정보처리방침](https://policies.google.com/privacy)을 따릅니다.
2. **음식 설명 보기를 누른 경우**: 해당 메뉴 이름이 설명을 가져오기 위해 한국어 위키백과(ko.wikipedia.org)로 전송됩니다.
3. **음성 입력을 사용하는 경우**: 앱은 Android 기본 음성 인식 기능을 호출합니다. 음성 처리는 이용자 기기의 음성 인식 서비스(예: Google)가 담당하며, 기기 설정에 따라 해당 서비스의 서버에서 처리될 수 있습니다. 앱은 음성 파일을 저장하지 않습니다.
4. **환율 조회**: 메뉴 가격을 원화로 환산하기 위해 앱이 환율 정보 서비스(frankfurter.dev, 유럽중앙은행 기준 환율)에 엔-원 환율을 요청합니다. 요청에는 이용자의 사진, 메뉴, 개인정보가 포함되지 않으며, 일반적인 인터넷 통신과 같이 접속 IP 주소가 서비스 제공자에게 전달될 수 있습니다. 조회한 환율은 기기에 저장되어 6시간 동안 재사용됩니다.
5. **번역 언어팩 다운로드**: 최초 1회 일본어↔한국어 언어팩을 Google ML Kit에서 내려받습니다. 이때 이용자의 개인정보는 전송되지 않습니다.

위 전송은 모두 암호화된 통신(HTTPS)으로 이루어집니다.

## 4. 개인정보의 보관 및 삭제

- 앱은 서버에 개인정보를 보관하지 않습니다.
- 기기에 저장된 스캔 기록은 앱 안에서 삭제하거나 앱을 삭제하면 모두 지워집니다.

## 5. 제3자 제공

앱은 이용자의 개인정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다. 앱에는 광고와 사용자 추적(분석) 도구가 없습니다.

## 6. 아동의 개인정보

앱은 만 14세 미만 아동을 주 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.
